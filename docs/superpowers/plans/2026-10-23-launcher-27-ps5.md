# Launcher 2.7 + PS5 Remote Play Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a boot-safe TV Home (cleanyourtv 2.7 plus our patches) and PS5 Remote Play to the XNANO X5, proven on an Android 11 emulator first.

**Architecture:** Fresh upstream clone at `~/Projects/cleanyourtv-27`; our 2.2 patch set is replayed onto it as one diff. Boot safety comes from never making TV Home the preferred Home: the stock launcher stays enabled and 2.7's `HomeKeyService` (`stock_home_redirect`) sends its home screen back to TV Home. Every check runs on an emulator before the projector is touched.

**Tech Stack:** Java Android app (Gradle), JDK 17 at `/opt/homebrew/opt/openjdk@17`, Android SDK at `/opt/homebrew/share/android-commandlinetools`, system image `android-30;default;arm64-v8a`, adb, zsh test scripts.

## Global Constraints

- Never touch the projector before Task 6, and Task 6 only after the owner sees the Task 4-5 report.
- Never run `cmd package set-home-activity` with TV Home, and never disable `com.zhenhuo.elevenlauncher`.
- After any `pm enable`/`pm disable-user` on a device, wait at least 30 s before a reboot (PackageManager writes package-restrictions about 10 s later).
- Do not add, remove or change any app on the projector except TV Home and PS Remote Play. NetMirror stays untouched.
- Third-party APKs are installed only after their signing certificate is checked (`apksigner verify --print-certs`).
- Dock stays Netflix, YouTube, Prime, AirPlay; 4 columns.
- Disk: about 11 GB free. Keep one AVD only, data partition 4 GB.

### Task 3: Boot-safety test script (write the failing test first)

**Files:** Create `~/Projects/tvhome/tools/emu-boot-test.sh`.

- [ ] **Step 1:** Write the test:
```bash
#!/bin/zsh
# Usage: emu-boot-test.sh <serial> <runs>. Fails if any cold boot does not complete in 180 s
# or logcat shows the ResolverActivity HOME loop that froze the X5 on 2026-10-23.
S=$1; N=${2:-5}; fail=0
for r in $(seq 1 $N); do
  adb -s $S reboot; adb -s $S wait-for-device
  ok=0; for t in $(seq 1 90); do [ "$(adb -s $S shell getprop sys.boot_completed | tr -d '\r')" = 1 ] && { ok=1; break; }; sleep 2; done
  loops=$(adb -s $S logcat -d | grep -c 'Unable to find explicit activity class {com.gathin.tvhome')
  top=$(adb -s $S shell dumpsys activity activities | grep -m1 mResumedActivity)
  echo "run $r boot=$ok resolver_loops=$loops top=$top"
  [ $ok = 1 ] && [ $loops -lt 3 ] || fail=1
  sleep 35
done
exit $fail
```
- [ ] **Step 2:** Prove it catches the bug. On the emulator install the old 2.2 APK `~/Projects/sony-tv-setup/apks/launcher-gathin-appletv.apk`, run `adb shell cmd package set-home-activity com.gathin.tvhome/.MainActivity`, wait 35 s, run `emu-boot-test.sh emulator-5554 1`. Expected: FAIL (boot=0 or resolver_loops high). If the emulator does not reproduce it, record that, and keep the test as a regression guard anyway.
- [ ] **Step 3:** Restore: `adb shell pm uninstall com.gathin.tvhome`, wait 35 s, reboot.
